FileZipper

Back-End: File Compression and Uploader Tool
A command-line tool built in Java that compresses a directory or file and streams it to a destination bucket on AWS S3.

Project Description

FileZipper is a command line tool that zips a file or folder/directory, then sends it using Java Streams to a specified Amazon Web Services Simple Storage Service bucket. It is cross-platform, and works in Linux/Unix, Mac OS, and Windows operating systems.

My Role

As the sole developer of this tool, I leveraged preexisting internal libraries to build FileZipper. The logic for streaming was mostly completed, so I my work included implementing a user-friendly system for accepting arguments, and a robust file/folder zipping method. This system is being reused in the 360Works.cloud backend to facilitate keeping records of FileMaker Server backups.
